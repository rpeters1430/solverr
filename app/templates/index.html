Deploying Solverr on Synology NAS & Docker

                    

                    

                        
Method 1: Synology Container Manager (GUI)

                        
    
                            
  1. Open Container Manager on your Synology NAS DSM.
    2. 
                            
  2. Go to Project → Click Create.
    3. 
                            
  3. Set Project Name: solverr.
    4. 
                            
  4. Choose path or create a folder: /docker/solverr.
    5. 
                            
  5. Select Create docker-compose.yml and paste the following snippet:
    6. 
                        


                        
version: '3.8'
services:
  solverr:
    image: solverr:latest  # or build locally
    container_name: solverr
    restart: unless-stopped
    ports:
      - "8191:8191"
    environment:
      - PORT=8191
      - MAX_BROWSER_WORKERS=auto
      - ENABLE_FAST_TLS=true
      - COOKIE_CACHE_TTL=7200
    volumes:
      - ./data:/app/data
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8191/health"]
      interval: 30s
      timeout: 5s
      retries: 3
